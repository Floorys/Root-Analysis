# HideRoot Lab

Статический локальный анализатор отчётов Android-детекторов и справочник методов диагностики.

## Запуск

Откройте `index.html` в браузере. Сервер и сборка не нужны; файлы отчётов обрабатываются локально.

Для локального HTTP-сервера при необходимости:

```bash
python3 -m http.server 8080
```

Затем откройте `http://localhost:8080`.

## Интерфейс

- Тёмное оформление с приглушённым зелёным акцентом, примером разбора на главном экране и нумерованным справочником с фильтрами платформ.
- На узких экранах разделы выстраиваются в одну колонку. Движение элементов учитывает системную настройку уменьшения анимации.
- Чтение и анализ сопровождаются состоянием загрузки; кнопка **Очистить** отменяет ожидающую операцию. Ошибки появляются рядом с вводом, пустой поиск предлагает сбросить фильтры.
- Шрифты **Geist** и **JetBrains Mono** с кириллицей включены в `assets/fonts/`. Они загружаются локально; лицензии SIL OFL находятся в том же каталоге.

## Язык интерфейса

- Переключатель **RU / EN** в шапке переводит интерфейс, справочник, результаты анализа и план действий.
- Выбранный язык сохраняется в браузере (`localStorage`, ключ `hideroot-language`) и восстанавливается при следующем открытии.
- При переключении сохраняются введённый текст, поиск, фильтры и раскрытые карточки. Поиск по справочнику понимает русские и английские названия и описания.
- Служебные пояснения и детали демо переводятся; цитаты из загруженного отчёта отображаются на языке оригинала.
- Словари находятся в `assets/i18n.js`. Для работы обоих языков подключение к интернету не требуется.

## Поддерживаемый ввод

- полные TXT-отчёты DUCK Detector;
- короткие текстовые и logcat-выгрузки с явными индикаторами;
- JSON-подобные результаты Play Integrity;
- вставка текста, выбор файла и drag-and-drop (до 5 МБ).
