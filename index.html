    02 / ПУТЕВОДИТЕЛЬ

    Лечение устройств

    Справочник по устранению реальных сбоев SELinux, монтирований, модулей и системных сервисов без удаления root.

    КАТЕГОРИЯ

    Снимок диагностики (read-only)

    Выполните на ПК по ADB, чтобы собрать getenforce, avc, монтирования, модули и ошибки сервисов в один текстовый лог:

    adb shell "echo getenforce:$(getenforce); dmesg | grep -i avc | tail -n 25; cat /proc/mounts; ls -la /data/adb/modules; logcat -b main,system,crash -d -t 80 *:E"

    Симптом → проверка → шаг починки

    04 / БАЗОВАЯ ПРОВЕРКА

    Перед повторным сканом

    Меняй по одному компоненту и повторяй тест после каждого шага — иначе источник улучшения или регрессии будет неясен.

    Один шаг. Один новый отчёт.

    1. 01

      Зафиксируй состояние

      Сохрани исходный отчёт, версии ядра, менеджера и модулей. Это твоя точка сравнения.

    2. 02

      Устрани критичное

      Сначала DANGER: SELinux, TEE, boot state. Косметические package-сигналы оставь на потом.

    3. 03

      Убери противоречия

      Согласуй props, attestation и runtime. Отключённая настройка при активном сервисе — сильный сигнал.

    4. 04

      Перезагрузи и проверь

      После системных модулей нужна полная перезагрузка. Новый отчёт сравни с исходным.
